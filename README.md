# AI Front Desk Assistant for Dental Practices

A demo of an AI-powered front desk assistant concept for dental practices.

## Overview

This project demonstrates how AI could assist dental practices with:

- Answering common patient enquiries
- Handling appointment scheduling
- Providing information about treatments
- Triage and escalation workflows

## Demo

Live demo: https://jazblue.github.io/Dentist/

## What It Shows

- Natural language understanding for dental enquiries
- Appointment booking workflow
- Cost estimates for common procedures
- WhatsApp integration mockup

## Purpose

Proof-of-concept for AI in healthcare administration. Not a production system.
